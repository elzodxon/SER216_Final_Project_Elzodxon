# SER216 Final Project - Digital Parking Permit System

## Project Description
This project describes a Digital Parking Permit System for a university. Students and staff can register vehicles, request parking permits, check available parking zones, and report parking issues. Security staff can verify permits and update violation records.

## Tools Used
- diagrams.net style workflow diagram
- Google Sheets compatible test case table
- PDF final report
- GitHub for version control, branching, pull request evidence, and final submission

## Repository Structure
- `final_report.pdf` - final submitted project report
- `diagrams/workflow_diagram.png` - workflow diagram
- `tables/test_cases.xlsx` - test case table
- `screenshots/` - GitHub evidence screenshots or placeholders to replace with real screenshots
- `notes/tools_used.md` - tools and workflow notes

## Workflow
Vehicle Registration -> Permit Request -> Zone Check -> Permit Approval -> Parking Verification

The repository is prepared with project files, meaningful commits, and a feature branch workflow. The final PDF includes the repository link and a GitHub evidence checklist.
