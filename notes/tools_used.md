# Tools Used

- GitHub repository for source control and final evidence.
- Git branches and commits for change tracking.
- Pull request workflow for review and merge evidence.
- diagrams.net style workflow diagram for the parking permit process.
- Spreadsheet table for test cases.
- PDF report for final submission.

## Project Workflow

1. Create repository and README.
2. Add requirements, workflow diagram, test table, and defect analysis.
3. Create a feature branch.
4. Commit project files in meaningful steps.
5. Open and merge a pull request.
6. Upload final PDF and include the GitHub repository link in the report.
